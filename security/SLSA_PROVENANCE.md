## Provenance Artifacts

Each release produces:

```
artifacts/release/
├── SBOM.json              # CycloneDX Software Bill of Materials
├── PROVENANCE.json        # SLSA provenance attestation
├── CHECKSUMS.sha256       # SHA-256 checksums of all release files
├── MODEL_MANIFEST.json    # Model artifact checksums and sources
├── DEPENDENCY_LOCK.txt    # Pinned dependency lockfile
└── BUILD_LOG.txt          # Reproducible build log
```

## Build Verification

To verify a release:

```bash
# Verify source integrity
sha256sum -c CHECKSUMS.sha256

# Verify SBOM matches installed packages
pip list --format=json | python tools/verify_sbom.py SBOM.json

# Verify model checksums
python tools/verify_model_manifest.py MODEL_MANIFEST.json

# Verify provenance signature
cosign verify-blob --signature PROVENANCE.sig PROVENANCE.json
```

## Dependency Provenance

| Dependency Type | Provenance Method | Verification |
|----------------|-------------------|--------------|
| Python packages | `requirements_lock.txt` with hashes | `pip install --require-hashes` |
| System packages | Dockerfile `apt-get` with pinned versions | Reproducible base image |
| Model weights | `MODEL_MANIFEST.json` with SHA-256 | Checksum verification on load |
| Configuration | Version-controlled in repo | Git commit hash |
